# 🎬 Netflix Data Cleaning and Analysis

## 📌 Project Overview

This project focuses on cleaning and exploring the Netflix Movies and TV Shows dataset using Python. The objective is to prepare raw Netflix data for analysis and understand the content available on the platform.

## 🎯 Project Objectives

* Clean and preprocess the Netflix dataset.
* Handle missing and duplicate values.
* Analyze movies and TV shows.
* Explore content distribution by country and genre.
* Prepare a cleaned dataset for further analysis.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* SQL
* Microsoft Excel
* Power BI

## 🔍 Data Cleaning Process

The following data preparation activities were performed:

1. Loaded the Netflix dataset using Pandas.
2. Checked missing and duplicate values.
3. Handled missing values.
4. Converted and formatted date-related columns.
5. Processed duration information.
6. Cleaned country and genre-related fields.
7. Prepared the cleaned dataset for further analysis.
8. Exported the cleaned data into Excel format.

## 📊 Key Analysis Areas

* Movies vs TV Shows distribution.
* Content distribution by country.
* Netflix content ratings.
* Release year analysis.
* Genre and category analysis.
* Movie and TV show duration.

## 📁 Dataset

The project uses the Netflix Movies and TV Shows dataset.

## 💡 Project Outcome

Successfully prepared a cleaned Netflix dataset using Python and Pandas, making it suitable for further exploratory data analysis and visualization.
